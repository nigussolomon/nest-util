# Migration Guide: nest-util v0.0.x → v0.1.x

This guide covers upgrading from the pre-upgrade nest-util packages (TypeORM 0.3.x, separate `@nest-util/nest-audit`) to the current version (TypeORM 1.1.0, audit merged into nest-crud).

## Quick Reference

- [ ] Upgrade `typeorm` to `^1.1.0`
- [ ] Run `npx @typeorm/codemod v1` (recommended)
- [ ] Remove `entitySkipConstructor: true` from ORM config
- [ ] Uninstall `@nest-util/nest-audit`
- [ ] Replace all `@nest-util/nest-audit` imports with `@nest-util/nest-crud`
- [ ] Remove `NestUtilNestAuditModule` from module imports
- [ ] Ensure `autoLoadEntities: true` on `TypeOrmModule.forRoot()`
- [ ] Update `@nestjs/swagger` to `^11.2.6`
- [ ] Install Express 5 (`^5.2.1`) if not present
- [ ] Add `'findMine'` to `disabledEndpoints` if you don't want `GET /mine`

---

## Step 1: Upgrade TypeORM

**Breaking:** TypeORM upgraded from `^0.3.28` to `^1.1.0`.

```bash
pnpm add typeorm@^1.1.0
```

Run the official codemod to auto-update syntax:

```bash
npx @typeorm/codemod v1
```

### Manual changes may be needed:

**Remove `entitySkipConstructor`:**

```diff
// ormconfig.ts or DataSource options
- entitySkipConstructor: true,
```

**Update relations syntax (if using `eager: true` for select-only):**

```diff
// Before (TypeORM 0.3.x)
- @ManyToOne(() => User, { eager: true })
+ @ManyToOne(() => User, { select: true })
```

## Step 2: Remove `@nest-util/nest-audit`

**Breaking:** `@nest-util/nest-audit` has been deleted entirely. All audit functionality is now part of `@nest-util/nest-crud`.

```bash
pnpm remove @nest-util/nest-audit
```

### Import Replacement Table

| Old Import | New Import |
|---|---|
| `import { Audit } from '@nest-util/nest-audit'` | `import { Audit } from '@nest-util/nest-crud'` |
| `import { AuditLogEntity } from '@nest-util/nest-audit'` | `import { AuditLogEntity } from '@nest-util/nest-crud'` |
| `import { AuditInterceptor } from '@nest-util/nest-audit'` | `import { AuditInterceptor } from '@nest-util/nest-crud'` |
| `import { AuditService } from '@nest-util/nest-audit'` | `import { AuditService } from '@nest-util/nest-crud'` |
| `import { ListAuditLogsDto } from '@nest-util/nest-audit'` | `import { ListAuditLogsDto } from '@nest-util/nest-crud'` |
| `import { CreateAuditLogInput } from '@nest-util/nest-audit'` | `import { CreateAuditLogInput } from '@nest-util/nest-crud'` |
| `import { NestUtilNestAuditModule } from '@nest-util/nest-audit'` | **DELETE** — no longer needed |

## Step 3: Update Module Configuration

### Before

```typescript
import { NestCrudModule } from '@nest-util/nest-crud';
import { NestUtilNestAuditModule } from '@nest-util/nest-audit';
import { AuditInterceptor } from '@nest-util/nest-audit';

@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: 'postgres',
      autoLoadEntities: true,
      // ...
    }),
    NestCrudModule,
    NestUtilNestAuditModule,  // ← REMOVE THIS
    AuthModule.forRoot({ /* ... */ }),
  ],
  providers: [
    { provide: APP_INTERCEPTOR, useClass: AuditInterceptor },
  ],
})
export class AppModule {}
```

### After

```typescript
import { NestCrudModule, AuditInterceptor } from '@nest-util/nest-crud';

@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: 'postgres',
      autoLoadEntities: true,  // ← REQUIRED: NestCrudModule registers AuditLogEntity internally
      // ...
    }),
    NestCrudModule,            // ← alone is sufficient
    AuthModule.forRoot({ /* ... */ }),
  ],
  providers: [
    { provide: APP_INTERCEPTOR, useClass: AuditInterceptor },
  ],
})
export class AppModule {}
```

**Key changes:**
- `NestUtilNestAuditModule` removed — `NestCrudModule` now provides `AuditService` and registers `AuditLogEntity`
- `autoLoadEntities: true` is required since `NestCrudModule` internally calls `TypeOrmModule.forFeature([AuditLogEntity])`
- `AuditInterceptor` now imported from `@nest-util/nest-crud`

## Step 5: Handle New `GET /mine` Route

A new `GET /<resource>/mine` endpoint is now generated by `CreateNestedCrudController`. It is mounted automatically but returns 404 unless configured.

### To disable it (no changes needed):

If your service doesn't configure `userOwnershipField` or `findMineQuery`, the endpoint returns 404 by default. No action required.

### To explicitly disable it:

```typescript
super({
  repository,
  disabledEndpoints: ['findMine'],  // ← suppresses GET /mine
});
```

### To enable it:

See [SKILL.md](./.opencode/skills/nest-util/SKILL.md) for the full `findMine` configuration.

## Step 6: Adopt New Features (Optional)

All new features are backward-compatible. Existing code continues to work without changes.

### Lifecycle Hooks

```typescript
super({
  repository,
  hooks: {
    beforeCreate: {
      handler: async (ctx) => { /* validate, transform */ },
      transaction: true,  // runs inside a DB transaction
    },
    afterCreate: {
      handler: async (ctx) => { /* send events, notify */ },
    },
  },
  transactionConfig: {
    isolationLevel: 'READ COMMITTED',
  },
});
```

### Cursor-Based Pagination

Existing `GET /` endpoints now accept `?cursor=<opaque>` for cursor pagination:

```bash
# First page
GET /posts?limit=10

# Next page (use nextCursor from previous response)
GET /posts?cursor=eyJpZCI6MTB9&limit=10

# With total count
GET /posts?cursor=eyJpZCI6MTB9&limit=10&includeTotal=true
```

No code changes needed — the controller automatically dispatches to cursor pagination when `?cursor` is present.

### findMine

```typescript
// Service
super({
  repository,
  userOwnershipField: 'authorId',  // simple column match
});

// Or for complex ownership (e.g., author OR collaborator)
super({
  repository,
  findMineQuery: (qb, userId) => {
    qb.where('e.authorId = :userId', { userId })
      .orWhere('e.id IN (SELECT postId FROM post_collaborators WHERE userId = :userId)', { userId });
  },
});
```

Controller must have `enableFindMine: true`:

```typescript
const PostControllerBase = CreateNestedCrudController(
  CreatePostDto, UpdatePostDto, Post,
  { enableFindMine: true }
);
```

## Troubleshooting

### "Cannot find module '@nest-util/nest-audit'"

Remove all imports from `@nest-util/nest-audit` and replace with `@nest-util/nest-crud`. See the [import replacement table](#import-replacement-table).

### "AuditLogEntity is not registered"

Ensure `autoLoadEntities: true` is set on your `TypeOrmModule.forRoot()` configuration.

### " findMine not configured"

The `GET /mine` endpoint requires either `userOwnershipField` or `findMineQuery` in your service options, and `enableFindMine: true` in your controller factory.

### TypeORM 1.x query builder changes

TypeORM 1.x has minor API changes. Run `npx @typeorm/codemod v1` to auto-fix most issues. Common manual fixes:

- `entitySkipConstructor` removed
- `Repository.findOne()` options may differ slightly
- `SelectQueryBuilder` is now imported from `typeorm` directly

### Hooks not firing

Ensure hooks are passed as `CrudHookConfig` objects with a `handler` property:

```typescript
// Correct
hooks: {
  beforeCreate: {
    handler: async (ctx) => { /* ... */ },
  },
}

// Incorrect — missing handler wrapper
hooks: {
  beforeCreate: async (ctx) => { /* ... */ },
}
```
