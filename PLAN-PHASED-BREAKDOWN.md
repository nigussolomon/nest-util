## Rollback Commands

### Per-Phase Rollback
```bash
git reset --soft HEAD~1  # Undo last commit, keep changes
git checkout -- .        # Discard all changes
```

### Full Plan Rollback
```bash
git reset --hard [commit-hash-before-plan]
pnpm install
```

### Emergency Rollback (All Plans)
```bash
git checkout publish
git reset --hard origin/publish
pnpm install
```
