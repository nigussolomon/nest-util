Define Once, Get Everything

Extend NestCrudService with your entity and DTOs. Filtering, pagination, hooks, and audit logging are automatic.

  • Whitelist filterable & sortable fields
  • Auto-join relations with include
  • Resolve foreign keys with relations
  • Add lifecycle hooks with transaction support
post.service.ts
@Injectable()
export class PostService extends NestCrudService<Post, CreatePostDto, UpdatePostDto> {
  constructor(@InjectRepository(Post) repo: Repository<Post>) {
    super({
      repository: repo,
      allowedFilters: ['title', 'authorId'],
      allowedSortFields: ['createdAt', 'title'],
      include: ['author'],
      userOwnershipField: 'authorId',
      hooks: {
        afterCreate: {
          handler: async (ctx) => {
            // Send notifications, emit events
          },
        },
      },
    });
  }
}

Full REST API in Seconds

CreateNestedCrudController generates all standard endpoints with Swagger docs, audit decorators, and permission metadata.

  • 7 endpoints generated automatically
  • Built-in @Audit() on mutations
  • Permission registry integration
  • Optional findMine with auth
post.controller.ts
const PostBase = CreateNestedCrudController(
  CreatePostDto, UpdatePostDto, Post,
  {
    permissions: buildCrudPermissionsFromRegistry(
      permissionRegistry, { resource: 'posts' }
    ),
    enableFindMine: true,
  }
);

@ApiTags('post')
@Controller('post')
@ApiBearerAuth()
@UseGuards(JwtAuthGuard, PermissionsGuard)
export class PostController extends PostBase {
  constructor(override readonly service: PostService) {
    super(service);
  }
}

Lifecycle Hooks

Intercept any CRUD operation with before/after hooks — with optional transaction wrapping.

hooks.interface.ts
interface CrudHooks<TEntity, TCreateDto, TUpdateDto> {
  beforeCreate?: CrudHookConfig<{ payload: TCreateDto }>;
  afterCreate?:  CrudHookConfig<{ entity: TEntity; payload: TCreateDto }>;
  beforeUpdate?: CrudHookConfig<{ payload: TUpdateDto; entity: TEntity; id: number }>;
  afterUpdate?:  CrudHookConfig<{ entity: TEntity; payload: TUpdateDto; id: number }>;
  beforeRemove?: CrudHookConfig<{ entity: TEntity; id: number }>;
  afterRemove?:  CrudHookConfig<{ id: number; deleted: boolean }>;
  beforeFindOne?: CrudHookConfig<{ id: number }>;
  afterFindOne?:  CrudHookConfig<{ entity: TEntity; id: number }>;
}

interface CrudHookConfig<TContext> {
  handler: (context: TContext) => Promise<any> | any;
  transaction?: boolean;  // wraps in DB transaction
}

interface TransactionConfig {
  isolationLevel?: 'READ UNCOMMITTED' | 'READ COMMITTED'
    | 'REPEATABLE READ' | 'SERIALIZABLE';
  timeout?: number;
}

Get Started in 3 Steps

From zero to production-ready CRUD API in minutes.

pnpm add @nest-util/nest-crud @nest-util/nest-auth typeorm@^1.1.0 @nestjs/typeorm
1

Create Entity & Service

Define your TypeORM entity, then extend NestCrudService with filters, hooks, and ownership.

2

Generate Controller

Use CreateNestedCrudController to generate 7 REST endpoints with Swagger docs and audit logging.

3

Wire Up AppModule

Import NestCrudModule, register global interceptors, and you're ready for production.

app.module.ts
@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: 'postgres',
      autoLoadEntities: true,
      // ... connection options
    }),
    NestCrudModule,
    AuthModule.forRoot({
      userEntity: User,
      identifierField: 'email',
      passkeyField: 'password',
      jwtSecret: process.env.JWT_SECRET,
    }),
  ],
  providers: [
    { provide: APP_INTERCEPTOR, useClass: ResponseInterceptor },
    { provide: APP_INTERCEPTOR, useClass: AuditInterceptor },
  ],
})
export class AppModule {}
