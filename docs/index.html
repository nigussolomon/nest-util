JWT Auth + RBAC

Token rotation, nonce validation, OTP, password reset, and role-based access control. One module, full config.

Audit Events

Define Once, Get Everything

Extend NestCrudService with your entity and DTOs. Filtering, pagination, hooks, and audit logging come free.

  • Whitelist filterable & sortable fields
  • Auto-join relations with include
  • Resolve foreign keys with relations
  • Lifecycle hooks with transaction support
post.service.ts
@Injectable()
export class PostService extends NestCrudService<Post, CreateDto, UpdateDto> {
  constructor(@InjectRepository(Post) repo: Repository<Post>) {
    super({
      repository: repo,
      allowedFilters: ['title', 'authorId'],
      allowedSortFields: ['createdAt', 'title'],
      include: ['author'],
      userOwnershipField: 'authorId',
      hooks: {
        afterCreate: {
          handler: async (ctx) => {
            // notifications, events, etc.
          },
        },
      },
    });
  }
}

Full REST API in Seconds

CreateNestedCrudController generates all endpoints with Swagger docs, audit decorators, and permission metadata.

  • 7 endpoints generated automatically
  • Built-in @Audit() on mutations
  • Permission registry integration
  • Optional findMine with auth
post.controller.ts
const PostBase = CreateNestedCrudController(
  CreatePostDto, UpdatePostDto, Post,
  {
    permissions: buildCrudPermissionsFromRegistry(
      permissionRegistry, { resource: 'posts' }
    ),
    enableFindMine: true,
  }
);

@ApiTags('post')
@Controller('post')
@UseGuards(JwtAuthGuard, PermissionsGuard)
export class PostController extends PostBase {
  constructor(override readonly svc: PostService) {
    super(svc);
  }
}

hooks in service options
hooks: {
  beforeCreate: {
    handler: async (ctx) => {
      ctx.payload.title = ctx.payload.title.trim();
    },
  },
  afterCreate: {
    handler: async (ctx) => {
      await this.notifications.send(ctx.entity);
    },
  },
  beforeRemove: {
    handler: async (ctx) => {
      if (ctx.entity.published)
        throw new BadRequestException('Cannot delete published');
    },
    transaction: true,
  },
}

Pluggable Audit Events

50+ typed events emitted for every operation. Write a handler, register it, done.

  • CRUD: create, update, delete, findAll, findOne
  • Auth: login, register, OTP, password reset
  • RBAC: role create, assign, remove, permissions
  • Guards: JWT denied, permissions denied
  • Glob-based include/exclude filtering
app.module.ts
import { AuditEventModule, ConsoleHandler } from '@nest-util/nest-crud';

class PostHogHandler implements AuditEventHandler {
  handle(event: AuditEvent) {
    posthog.capture({
      distinctId: String(event.userId),
      event: event.action,
      properties: event.metadata,
    });
  }
}

@Module({
  imports: [
    AuditEventModule.forRoot({
      handlers: [
        new ConsoleHandler(),
        new PostHogHandler('ph_key'),
      ],
      include: ['auth.*', 'crud.*'],
    }),
  ],
})

Test Every Endpoint

Import crudServiceTests or crudControllerTests and get ~35 tests from your entity metadata.

  • Covers all 7 CRUD endpoints
  • Tests filters, pagination, sorting
  • Verifies disabled endpoint guards
  • Checks permission metadata
  • Mock repository with generated data
post.service.spec.ts
import { crudServiceTests } from '@nest-util/nest-crud/testing';
import { PostService } from './post.service';
import { Post } from './post.entity';

describe('PostService', () => {
  crudServiceTests({
    serviceClass: PostService,
    entity: Post,
    allowedFilters: ['title'],
    userOwnershipField: 'authorId',
    test: {
      createPayload: { title: 'Hello' },
      updatePayload: { title: 'Updated' },
    },
  });
});

Wire Up AppModule

Import NestCrudModule, register interceptors, deploy.

app.module.ts
@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: 'postgres',
      autoLoadEntities: true,
      // ...
    }),
    NestCrudModule,
    AuthModule.forRoot({
      userEntity: User,
      identifierField: 'email',
      passkeyField: 'password',
      jwtSecret: process.env.JWT_SECRET,
    }),
  ],
  providers: [
    { provide: APP_INTERCEPTOR, useClass: ResponseInterceptor },
    { provide: APP_INTERCEPTOR, useClass: AuditInterceptor },
  ],
})
export class AppModule {}
