nest-auth

JWT authentication with refresh token rotation, RBAC, OTP login, and password reset — ready out of the box.

🔒

JWT + Refresh Rotation

Short-lived access tokens with rotating refresh tokens and nonce validation for single-session security.

⚗

RBAC

Role-based access control with @Permissions() decorator and a pluggable permission registry.

⚡

OTP Login

One-time password login with configurable code length, cooldown, lockout, and delivery callbacks.

🔑

Password Reset

Token-based password reset with configurable expiry, hashed storage, and session invalidation.

Install

We recommend using pnpm as your package manager.

pnpm add @nest-util/nest-auth@^1.0.2 @nestjs/jwt @nestjs/passport typeorm@^1.1.0 @nestjs/typeorm @nestjs/swagger class-validator bcrypt

Prerequisites

  1. TypeORM must be configured in your application.
  2. Your User entity must include:
    • identifier field (e.g. email)
    • password field (e.g. password)
    • refreshToken — hashed refresh token storage
    • accessToken — hashed access token storage
    • (Optional, for OTP) otpCodeHash, otpCodeExpiresAt, otpRequestAttempts, otpLastSentAt, otpLockedUntil
    • (Optional, for Password Reset) passwordResetTokenHash, passwordResetTokenExpiresAt
  3. Create DTOs for login, register, and refresh payloads.
auth.dto.ts
import { ApiProperty } from '@nestjs/swagger';

export class LoginDto {
  @ApiProperty({ example: 'user@example.com' })
  email!: string;

  @ApiProperty({ example: 'password123' })
  password!: string;
}

export class RefreshDto {
  @ApiProperty()
  refreshToken!: string;
}

Auth Module

Register AuthModule.forRoot() in your root module with the full configuration.

app.module.ts
import { Module } from '@nestjs/common';
import { AuthModule } from '@nest-util/nest-auth';
import { User } from './user/user.entity';
import { LoginDto, RegisterDto, RefreshDto } from './auth/auth.dto';
import { permissionRegistry } from './auth/permission-registry';

@Module({
  imports: [
    AuthModule.forRoot({
      // Entity & fields
      userEntity: User,
      identifierField: 'email',
      passkeyField: 'password',

      // JWT configuration
      jwtSecret: process.env.JWT_SECRET ?? 'super-secret-key',
      refreshTokenSecret: process.env.REFRESH_TOKEN_SECRET,
      expiresIn: '1h',
      refreshTokenExpiresIn: '7d',

      // Token storage fields on User entity
      refreshTokenField: 'refreshToken',
      accessTokenField: 'accessToken',

      // DTOs
      loginDto: LoginDto,
      registerDto: RegisterDto,
      refreshDto: RefreshDto,

      // Relations loaded during JWT validation
      relations: ['userRoles', 'userRoles.role'],

      // RBAC configuration
      rbac: {
        userRolesRelation: 'userRoles',
        rolesKey: 'userRoles',
        nestedRoleKey: 'role',
      },

      // Permission registry for @Permissions() checks
      permissionRegistry,

      // Optionally disable specific routes
      disabledRoutes: [],

      // Password reset (optional)
      passwordReset: {
        enabled: true,
        tokenLength: 64,
        tokenTtlSeconds: 3600,
        tokenField: 'passwordResetTokenHash',
        expiresAtField: 'passwordResetTokenExpiresAt',
        deliverToken: async ({ identifier, token, expiresAt }) => {
          // Send email/SMS with the reset token
          console.log(`Send reset token ${token} to ${identifier}`);
        },
      },

      // OTP login (optional)
      otp: {
        enabled: true,
        codeLength: 6,
        ttlSeconds: 300,
        cooldownSeconds: 60,
        maxAttempts: 5,
        lockSeconds: 300,
        channel: 'email',
        deliverCode: async ({ identifier, code, expiresAt }) => {
          // Send email/SMS with the OTP code
          console.log(`Send OTP code ${code} to ${identifier}`);
        },
      },
    }),
  ],
})
export class AppModule {}

Endpoints

AuthModule provides these built-in endpoints under /auth:

Method Endpoint Description Auth
POST /auth/register Create a new user account Public
POST /auth/login Login with credentials, returns access & refresh tokens Public
POST /auth/refresh Rotate refresh token, return new token pair Public
GET /auth/me Get current authenticated user Required
POST /auth/update-password Update own password (current + new) Required
POST /auth/logout Invalidate current session tokens Required
GET /auth/me/permissions Get current user's resolved permissions Required
POST /auth/password-reset/request Request a password reset token Public
POST /auth/password-reset/reset Reset password with token, invalidates all sessions Public
POST /auth/otp/request Request an OTP code via delivery callback Public
POST /auth/otp/login Login with OTP code, returns auth tokens Public

Method Endpoint Description

PATCH /auth/roles/:id Update a role
DELETE /auth/roles/:id Delete a role
POST /auth/users/:id/roles Assign roles to a user
DELETE /auth/users/:id/roles/:roleId Remove a role from a user

Guards

Protect your endpoints with JwtAuthGuard for authentication and PermissionsGuard for authorization. Use the @CurrentUser() and @Permissions() decorators to access the authenticated user and enforce permissions.

profile.controller.ts
import { Controller, Get, UseGuards } from '@nestjs/common';
import {
  CurrentUser,
  JwtAuthGuard,
  Permissions,
  PermissionsGuard,
  type AuthUser,
} from '@nest-util/nest-auth';

@Controller('profile')
export class ProfileController {

  // Authenticated user profile
  @Get('me')
  @UseGuards(JwtAuthGuard)
  me(@CurrentUser() user: AuthUser) {
    return user;
  }

  // Admin-only endpoint
  @Get('admin')
  @UseGuards(JwtAuthGuard, PermissionsGuard)
  @Permissions('admin.access')
  adminOnly() {
    return { ok: true };
  }
}

Decorators

Decorator Guard Required Description
@CurrentUser() JwtAuthGuard Injects the authenticated AuthUser into the handler parameter
@Permissions('key') PermissionsGuard Requires the user to hold the specified permission
@Public() None Marks a route as public (skips JWT validation)

import { AuditEventModule, ConsoleHandler } from '@nest-util/nest-crud';

@Module({
  imports: [
    AuditEventModule.forRoot({
      handlers: [
        new ConsoleHandler(),
      ],
      include: ['auth.*'],
    }),
  ],
})

Quick Start

Get up and running in three steps.

1

Install the package

Run pnpm add @nest-util/nest-auth@^1.0.2 @nestjs/jwt @nestjs/passport typeorm@^1.1.0 @nestjs/typeorm @nestjs/swagger class-validator bcrypt and ensure TypeORM is configured with a User entity.

2

Register AuthModule

Add AuthModule.forRoot() to your root module imports with entity, secrets, and DTOs.

3

Protect endpoints

Apply JwtAuthGuard and PermissionsGuard to your controllers.

app.module.ts
@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: 'postgres',
      autoLoadEntities: true,
      // ... connection options
    }),
    AuthModule.forRoot({
      userEntity: User,
      identifierField: 'email',
      passkeyField: 'password',
      jwtSecret: process.env.JWT_SECRET,
      refreshTokenSecret: process.env.REFRESH_TOKEN_SECRET,
      expiresIn: '1h',
      refreshTokenExpiresIn: '7d',
      refreshTokenField: 'refreshToken',
      accessTokenField: 'accessToken',
      loginDto: LoginDto,
      registerDto: RegisterDto,
      refreshDto: RefreshDto,
      relations: ['userRoles', 'userRoles.role'],
      rbac: {
        userRolesRelation: 'userRoles',
        rolesKey: 'userRoles',
        nestedRoleKey: 'role',
      },
      permissionRegistry,
    }),
  ],
})
export class AppModule {}

Password Reset

Enable token-based password reset by adding the passwordReset option to AuthModule.forRoot(). You must provide a deliverToken callback to send the reset link or token to the user.

app.module.ts (passwordReset config)
AuthModule.forRoot({
  // ... other options
  passwordReset: {
    enabled: true,
    tokenLength: 64,          // Length of the generated token
    tokenTtlSeconds: 3600,    // Token validity (1 hour)
    tokenField: 'passwordResetTokenHash',
    expiresAtField: 'passwordResetTokenExpiresAt',
    deliverToken: async ({ identifier, token, expiresAt }) => {
      // Send email/SMS with the reset token or link
      console.log(`Send reset token ${token} to ${identifier}`);
    },
  },
})

Endpoints

Method Endpoint Description
POST /auth/password-reset/request Accepts { email }. Returns success even if the user doesn't exist (prevents account enumeration).
POST /auth/password-reset/reset Accepts { token, newPassword }. Invalidates all existing sessions upon success.

OTP Login

Enable One-Time Password login by adding the otp option to AuthModule.forRoot(). You must provide a deliverCode callback.

app.module.ts (otp config)
AuthModule.forRoot({
  // ... other options
  otp: {
    enabled: true,
    codeLength: 6,
    ttlSeconds: 300,         // Code validity (5 minutes)
    cooldownSeconds: 60,     // Min time between requests
    maxAttempts: 5,           // Max failed attempts before lockout
    lockSeconds: 300,         // Lockout duration
    channel: 'email',
    deliverCode: async ({ identifier, code, expiresAt }) => {
      // Send email/SMS with the OTP code
      console.log(`Send OTP code ${code} to ${identifier}`);
    },
  },
})

Endpoints

Method Endpoint Description
POST /auth/otp/request Accepts { email }. Triggers the deliverCode callback.
POST /auth/otp/login Accepts { email, otpCode }. Validates the code and returns auth tokens.

Help Notes

  • Refresh token field: The /auth/refresh endpoint currently expects refreshToken in the request body.
  • Nonce validation: Access and refresh tokens are validated against hashed nonce values stored in the database, enabling single-session token rotation. Each refresh rotates both tokens.
  • Relations requirement: If you enable RBAC, ensure relations includes the role relations needed during JWT validation (e.g. ['userRoles', 'userRoles.role']).
  • disabledRoutes: Use disabledRoutes to hard-disable selected auth endpoints (e.g. ['register', 'otp/request']). Disabled routes return 404.
