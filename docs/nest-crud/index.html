nest-crud

CRUD scaffolding, audit logging, lifecycle hooks, cursor pagination, findMine, and a testing factory — all in one package.

Install

We recommend using pnpm as your package manager.

pnpm add @nest-util/nest-crud@^1.0.6 @nest-util/nest-auth@^1.0.2 typeorm@^1.1.0 @nestjs/typeorm @nestjs/swagger @nestjs/jwt @nestjs/passport class-validator class-transformer bcrypt

@nest-util/nest-crud includes audit logging, lifecycle hooks, cursor pagination, findMine, and a testing factory — all built-in.

Service

Create your resource service by extending NestCrudService:

post.service.ts
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { NestCrudService } from '@nest-util/nest-crud';
import { Post } from './post.entity';
import { CreatePostDto } from './create-post.dto';
import { UpdatePostDto } from './update-post.dto';

@Injectable()
export class PostService extends NestCrudService<
  Post,
  CreatePostDto,
  UpdatePostDto
> {
  constructor(@InjectRepository(Post) repository: Repository<Post>) {
    super({
      repository,
      allowedFilters: ['title'],
      allowedSortFields: ['createdAt', 'title'],
      include: ['author'],
      userOwnershipField: 'authorId',
      hooks: {
        afterCreate: {
          handler: async (ctx) => {
            // Send notifications, emit events
          },
        },
      },
    });
  }
}

Service Options

crud-service-options.interface.ts
interface CrudServiceOptions<Entity, ResponseDto> {
  repository: Repository<Entity>;
  allowedFilters?: readonly (keyof Entity)[];
  allowedSortFields?: readonly (keyof Entity)[];
  include?: readonly string[];
  relations?: {
    property: keyof Entity;
    repo: Repository<ObjectLiteral>;
    idField?: string;
  }[];
  toResponseDto?: (entity: Entity | Entity[]) => ResponseDto | ResponseDto[];
  createDtoClass?: Type<unknown>;
  updateDtoClass?: Type<unknown>;
  disabledEndpoints?: readonly CrudEndpoint[];
  cursorStrategy?: CursorStrategy;          // override auto-detection
  hooks?: CrudHooks<Entity, any, any>;      // lifecycle hooks
  transactionConfig?: TransactionConfig;    // isolation level for hooks
  userOwnershipField?: keyof Entity;        // enables findMine
  findMineQuery?: (qb, userId) => void;     // custom findMine query
}
Field Type Description
repository Repository<Entity> TypeORM repository for the entity
allowedFilters readonly (keyof Entity)[] Whitelist of fields that can be filtered
allowedSortFields readonly (keyof Entity)[] Whitelist of fields that can be sorted
include readonly string[] Relations to auto-join (eager load)
relations { property, repo, idField? }[] Resolve payload foreign keys into related entities
toResponseDto (entity) => ResponseDto Transform entity to response DTO
createDtoClass Type<unknown> DTO class for create validation
updateDtoClass Type<unknown> DTO class for update validation
disabledEndpoints readonly CrudEndpoint[] Hide generated routes without rewriting controllers
cursorStrategy CursorStrategy Override auto-detection of integer vs UUID cursors
hooks CrudHooks<Entity> Lifecycle hooks for before/after CRUD actions
transactionConfig TransactionConfig Transaction isolation level and timeout for hooks
userOwnershipField keyof Entity Column that links entity to user (enables findMine)
findMineQuery (qb, userId) => void Custom query builder callback for complex ownership

Controller

CreateNestedCrudController generates all standard endpoints with Swagger docs, audit decorators, and permission metadata.

post.controller.ts
import { Controller, UseGuards } from '@nestjs/common';
import {
  CreateNestedCrudController,
  IBaseController,
} from '@nest-util/nest-crud';
import { ApiBearerAuth, ApiTags } from '@nestjs/swagger';
import {
  JwtAuthGuard,
  PermissionsGuard,
  buildCrudPermissionsFromRegistry,
} from '@nest-util/nest-auth';

const PostCrudControllerBase = CreateNestedCrudController(
  CreatePostDto,
  UpdatePostDto,
  Post,
  {
    permissions: buildCrudPermissionsFromRegistry(permissionRegistry, {
      resource: 'posts',
    }),
    enableFindMine: true,  // enables GET /post/mine
  }
) as abstract new (service: PostService) => IBaseController<
  CreatePostDto, UpdatePostDto, Post
>;

@ApiTags('post')
@Controller('post')
@ApiBearerAuth()
@UseGuards(JwtAuthGuard, PermissionsGuard)
export class PostController extends PostCrudControllerBase {
  constructor(override readonly service: PostService) {
    super(service);
  }
}

Controller Options

Option Type Description
permissions CrudPermissions Permission strings for each endpoint, integrated with PermissionsGuard
enableFindMine boolean Enables the GET /resource/mine endpoint (requires auth)

Lifecycle Hooks

Intercept any CRUD operation with before/after hooks — with optional transaction wrapping.

hooks.interface.ts
interface CrudHooks<TEntity, TCreateDto, TUpdateDto> {
  beforeCreate?: CrudHookConfig<{ payload: TCreateDto }>;
  afterCreate?:  CrudHookConfig<{ entity: TEntity; payload: TCreateDto }>;
  beforeUpdate?: CrudHookConfig<{ payload: TUpdateDto; entity: TEntity; id: number }>;
  afterUpdate?:  CrudHookConfig<{ entity: TEntity; payload: TUpdateDto; id: number }>;
  beforeRemove?: CrudHookConfig<{ entity: TEntity; id: number }>;
  afterRemove?:  CrudHookConfig<{ id: number; deleted: boolean }>;
  beforeFindOne?: CrudHookConfig<{ id: number }>;
  afterFindOne?:  CrudHookConfig<{ entity: TEntity; id: number }>;
}

interface CrudHookConfig<TContext> {
  handler: (context: TContext) => Promise<any> | any;
  transaction?: boolean;  // wraps in DB transaction
}

interface TransactionConfig {
  isolationLevel?: 'READ UNCOMMITTED' | 'READ COMMITTED'
    | 'REPEATABLE READ' | 'SERIALIZABLE';
  timeout?: number;
}

Available Hooks

  • beforeCreate / afterCreate
  • beforeUpdate / afterUpdate
  • beforeRemove / afterRemove
  • beforeFindOne / afterFindOne

Transaction Config

Set transaction: true on any hook to wrap it inside a database transaction. Configure isolation level and timeout via transactionConfig in your service options.

Configuring Hooks

post.service.ts (hooks)
super({
  repository,
  hooks: {
    beforeCreate: {
      handler: async (ctx) => {
        // validate, transform
      },
      transaction: true,  // runs inside a DB transaction
    },
    afterCreate: {
      handler: async (ctx) => {
        // send events, notify
      },
    },
  },
  transactionConfig: {
    isolationLevel: 'READ COMMITTED',
  },
});

Cursor Pagination

Pass ?cursor=<opaque> to GET / for efficient keyset pagination on large datasets.

How It Works

  • Integer PKs: Uses id > cursor — fast index scan
  • UUID PKs: Uses composite (createdAt, id) cursors for stable ordering
  • Cursors are opaque base64url-encoded values — clients should not parse them

Usage Examples

cursor-pagination.sh
# First page
GET /posts?limit=10

# Next page — use the cursor from the previous response
GET /posts?cursor=eyJpZCI6MTB9&limit=10

# With total count (adds a DB COUNT query)
GET /posts?cursor=eyJpZCI6MTB9&limit=10&includeTotal=true

findMine

Retrieve user-scoped records via GET /resource/mine. Requires enableFindMine: true on the controller and userOwnershipField or findMineQuery on the service.

Simple Column Match

post.service.ts (findMine)
super({
  repository,
  userOwnershipField: 'authorId',
});

Custom Query Builder

post.service.ts (findMineQuery)
super({
  repository,
  findMineQuery: (qb, userId) => {
    qb.where('e.authorId = :userId', { userId })
      .orWhere('e.id IN (SELECT postId FROM post_collaborators WHERE userId = :userId)', { userId });
  },
});

Testing Factory

Generate complete test suites for your CRUD service and controller with zero boilerplate.

Service Tests

post.service.spec.ts
import { crudServiceTests } from '@nest-util/nest-crud/testing';
import { PostService } from './post.service';
import { Post } from './post.entity';
import { CreatePostDto } from './create-post.dto';
import { UpdatePostDto } from './update-post.dto';

describe('PostService', () => {
  crudServiceTests({
    serviceClass: PostService,
    entity: Post,
    createDto: CreatePostDto,
    updateDto: UpdatePostDto,
    allowedFilters: ['title'],
    userOwnershipField: 'authorId',
    test: {
      createPayload: { title: 'Hello', content: 'World' },
      updatePayload: { title: 'Updated' },
    },
  });
});

Generates ~20 tests covering findAll, findOne, create, update, remove, findMine, findAllWithCursor, findAuditLogs, and disabled endpoints.

Controller Tests

post.controller.spec.ts
import { crudControllerTests } from '@nest-util/nest-crud/testing';
import { CreateNestedCrudController } from '@nest-util/nest-crud';
import { PostService } from './post.service';
import { Post } from './post.entity';
import { CreatePostDto } from './create-post.dto';
import { UpdatePostDto } from './update-post.dto';

const PostControllerBase = CreateNestedCrudController(
  CreatePostDto, UpdatePostDto, Post,
  { enableFindMine: true }
);

describe('PostController', () => {
  crudControllerTests({
    controllerFactory: () => PostControllerBase,
    serviceClass: PostService,
    entity: Post,
    createDto: CreatePostDto,
    updateDto: UpdatePostDto,
    permissions: {
      findAll: 'posts.read',
      findOne: 'posts.read',
      create: 'posts.create',
      update: 'posts.update',
      remove: 'posts.delete',
      findAuditLogs: 'posts.audit',
      findMine: 'posts.read',
    },
    test: {
      createPayload: { title: 'Hello', content: 'World' },
      updatePayload: { title: 'Updated' },
    },
  });
});

Generates ~15 tests covering all endpoints, disabled endpoint guards, and permission metadata.

Filtering

Filtering uses the filter[field_operator]=value query parameter format.

Example

filtering.sh
# Exact match
GET /posts?filter[title_eq]=Hello

# Contains
GET /posts?filter[title_cont]=lo

# Greater than or equal
GET /posts?filter[createdAt_gte]=2024-01-01

# Multiple filters
GET /posts?filter[title_cont]=test&filter[authorId_eq]=1

Supported Operators

Operator Description
eqEqual to
neNot equal to
contContains (LIKE %value%)
notcontDoes not contain
startsStarts with (LIKE value%)
endsEnds with (LIKE %value)
gteGreater than or equal
lteLess than or equal
gtGreater than
ltLess than
inIn list (comma-separated)
ninNot in list
isnullIs null

Help Notes

  • disabledEndpoints: Use disabledEndpoints in service options to hide generated routes without rewriting controllers.
  • relations: The relations option lets you resolve propertyId payload fields into related entities automatically.
  • findAuditLogs: If findAuditLogs is not implemented in your service, /auditlogs returns not found by design.
  • findMine requirements: findMine returns 404 unless enableFindMine: true is set on the controller and userOwnershipField or findMineQuery is configured on the service.
  • Express query parser: Set app.set('query parser', 'extended') in bootstrap for deep object query parsing (required for filter syntax).
